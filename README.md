# Cewez-Calculator

Werkuren en loon bijhouden voor havenarbeid: kies per dag het startuur (shift), vul eventuele overuren in (na 7u45) en zie wat je per maand en per jaar bruto verdient.

- Open `index.html` in de browser (of via GitHub Pages).
- Tarieven komen uit de CEWEZ-tabel en zijn aan te passen in de app.
- Gegevens blijven op je toestel (browseropslag); maak af en toe een back-up via "Back-up & export".
